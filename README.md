# Python and Beyond

Python をゼロから学び、その先（機械学習、AI、因果推論、データを使った意思決定など）へ進むための、自学自習用の教材です。
Google Colab で開いて、そのまま動かせます。パソコンに何も入れる必要はありません。

（準備中です。教材は順に追加していきます。）

**使い方は自由です**：授業、勉強会、社内の研修、配る、直して使うなど、出典を書いていただければご自由にどうぞ（詳しくは下の「ライセンス」）。

## どこから始めるか

- **プログラミングが初めての人**：[教材1「Python」](1_python/README.md)の第1部を、第1回から順に
- **プログラミングは苦手だけど、何か作ってみたい人**：[教材3「AI と作る」](3_make_with_ai/README.md)から。AI に頼んでゲームを作ります。前提はいりません
- **教材1 第1部が終わった人**：下の表から、興味のある教材へ

教材の名前を押すと、その教材のページが開きます。そこにある「Colab で開く」のボタンを押すと、ノートブックが Colab で開きます。
