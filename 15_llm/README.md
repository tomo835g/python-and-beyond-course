# 教材15「大規模言語モデル」

LLM の仕組みを小さな GPT を作って確かめ、文章の整理、文書を読ませる、道具を使わせる、答えの確かめ方、追加学習まで。

前提：教材1 第1部

表の「Colab で開く」を押すと、そのまま Colab で開けます。開いたら、最初に自分のドライブにコピーを保存してください（やり方は教材1 第1部 第1回）。

分からないところは AI に聞いてみよう（やり方は教材1 第1部 第2回「分からないときは AI に聞く」）。

第3回と第10回は PyTorch を使います。必要なことはその回の中で説明するので、教材5「ディープラーニング」を読んでいなくても進められます。
